# Agent instructions

This repository contains the public social.plus documentation.

## Before writing or reviewing documentation

Every agent must read and follow [the documentation writing skill](.claude/skills/docs-style/SKILL.md) before drafting, editing, or reviewing documentation, including SDK and UIKit pages, feature introductions, and release notes.

Read the authoritative references identified by the skill that apply to the task. Follow its grounding workflow and its rules for integrator relevance and disclosure of internal information during both writing and review.

If your agent supports skill invocation, invoke `docs-style`. Otherwise, read the skill file directly; skill invocation support is not required to follow these instructions.

The writing skill and its authoritative references remain the source of truth for documentation policy. Do not duplicate their rules here.
