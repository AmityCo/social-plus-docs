Video posts combine uploaded videos with an optional text caption. Upload the videos first, then pass the uploaded video objects or file IDs to the post creation API.

<Info>
This page focuses on the SDK call that creates the post. See [Video Handling](/social-plus-sdk/core-concepts/content-handling/files-images-and-videos/video-handling) for upload steps, supported file inputs, processing behavior, and upload constraints.
</Info>

## Parameters

| Parameter | Required | Platforms | Description |
| --- | --- | --- | --- |
| `videos`, `uploadedVideos`, or `fileId` | Yes | TypeScript, iOS, Android, Flutter | Uploaded video objects or video file IDs, depending on SDK. |
| `text` | No | TypeScript, iOS, Android, Flutter | Caption text shown with the video post. |
| `targetType` | Yes | TypeScript, iOS, Android, Flutter | Feed target, usually `community` or `user`. |
| `targetId` | Yes | TypeScript, iOS, Android, Flutter | Community ID or user ID for the target feed. |
| `metadata` | No | TypeScript, iOS, Android, Flutter | Custom metadata stored with the post where supported. |
| `mentionees` | No | TypeScript, iOS, Android, Flutter | User mention payload where supported by the platform builder. |
| `productTags` | No | TypeScript, Android, iOS | Products tagged in the post text. Text product tag types: `Amity.TextProductTag`, `AmityTextProductTag`, `AmityProductTag.Text`. |
| `attachmentProductTags` | No | TypeScript, Android, iOS | Products tagged on individual video attachments. An `AmityAttachmentProductTags` container, keyed by each attachment's `fileId`. |

<Note>
**Product tags.** `productTags` tags products mentioned in the post **text**. `attachmentProductTags` tags products on individual **media attachments**, and is not an array: it is an `AmityAttachmentProductTags` container that maps each attachment's `fileId` to that attachment's media tags. Flutter does not expose product tags on any post builder. See [Tag Products](#tag-products) below for both. For tagging limits and tap-through behavior, see [Product Tagging](/uikit/components/social/posts#product-tagging).
</Note>

## Create a Video Post

The examples below create a video post in a community. Replace the target with the SDK's user-feed target when posting to a user.

<CodeGroup>

```swift iOS
func createVideoPost(
    uploadedVideos: [AmityVideoData],
    communityId: String
) async throws -> AmityPost {
    let postRepository = AmityPostRepository()
    let builder = AmityVideoPostBuilder()
    builder.setVideos(uploadedVideos)
    builder.setText("Video from today")

    return try await postRepository.createVideoPost(
        builder,
        targetId: communityId,
        targetType: .community,
        metadata: nil,
        mentionees: nil
    )
}
```

```kotlin Android
fun createVideoPost(
    uploadedVideos: Set<AmityVideo>,
    communityId: String
) {
    postRepository.createVideoPost(
        targetType = AmityPost.TargetType.COMMUNITY,
        targetId = communityId,
        videos = uploadedVideos,
        text = "Video from today"
    )
        .subscribe({ post ->
            showSuccessMessage(post.getPostId())
        }, { error ->
            handleGeneralError(error)
        })
}
```

```typescript TypeScript
import { PostRepository } from "@amityco/ts-sdk";

const { data: post } = await PostRepository.createPost({
  targetType: "community",
  targetId: communityId,
  data: {
    text: "Video from today",
  },
  attachments: [
    {
      type: "video",
      fileId,
    },
  ],
});
```

```dart Flutter
Future<AmityPost> createVideoPost(List<AmityVideo> uploadedVideos) {
  return AmitySocialClient.newPostRepository()
      .createPost()
      .targetCommunity(communityId)
      .video(uploadedVideos)
      .text('Video from today')
      .post();
}
```

</CodeGroup>

## Tag Products

TypeScript, Android, and iOS accept two separate product inputs when creating a video post.

| Input | Tags what | Shape |
| --- | --- | --- |
| `productTags` | Products named in the post text | An array of text product tags, each with a character range |
| `attachmentProductTags` | Products shown in one video | An `AmityAttachmentProductTags` container, keyed by `fileId` |

Build `attachmentProductTags` by setting the tags for each uploaded video's `fileId`. Videos you do not set tags for stay untagged.

<CodeGroup>

```swift iOS
let postRepository = AmityPostRepository()
let builder = AmityVideoPostBuilder()
builder.setVideos(uploadedVideos)
builder.setText("Wearing the Nike Air Max today")

let attachmentTags = AmityAttachmentProductTags()
attachmentTags.set(
    fileId: uploadedVideos[0].fileId,
    tags: [AmityMediaProductTag(productId: "prod_001")]
)

let post = try await postRepository.createVideoPost(
    builder,
    targetId: communityId,
    targetType: .community,
    metadata: nil,
    mentionees: nil,
    productTags: [
        AmityTextProductTag(productId: "prod_001", index: 12, length: 12)
    ],
    attachmentProductTags: attachmentTags
)
```

```kotlin Android
val attachmentTags = AmityAttachmentProductTags.Builder()
attachmentTags.set(
    uploadedVideos.first().getFileId(),
    listOf(AmityProductTag.Media(productId = "prod_001"))
)

postRepository.createVideoPost(
    targetType = AmityPost.TargetType.COMMUNITY,
    targetId = communityId,
    videos = uploadedVideos,
    text = "Wearing the Nike Air Max today",
    productTags = listOf(
        AmityProductTag.Text(
            productId = "prod_001",
            text = "Nike Air Max",
            index = 12,
            length = 12
        )
    ),
    attachmentProductTags = attachmentTags.build()
)
    .subscribe({ post ->
        showSuccessMessage(post.getPostId())
    }, { error ->
        handleGeneralError(error)
    })
```

```typescript TypeScript
import { AmityAttachmentProductTags, PostRepository } from "@amityco/ts-sdk";

const attachmentTags = new AmityAttachmentProductTags();
attachmentTags.set(fileId, [{ productId: "prod_001" }]);

const { data: post } = await PostRepository.createPost({
  targetType: "community",
  targetId: communityId,
  data: {
    text: "Wearing the Nike Air Max today",
  },
  attachments: [{ type: "video", fileId }],
  productTags: [
    { productId: "prod_001", text: "Nike Air Max", index: 12, length: 12 },
  ],
  attachmentProductTags: attachmentTags,
});
```

</CodeGroup>

## Notes

- TypeScript accepts video attachments as `{ type: "video", fileId }`.
- Android accepts a `Set<AmityVideo>`.
- iOS accepts `[AmityVideoData]`.
- Flutter accepts `List<AmityVideo>`.

For mixed attachment types, use [Mixed Media Posts](./mixed-media-post).
