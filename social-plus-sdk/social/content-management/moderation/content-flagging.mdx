title: "Content Flagging"
description: "Flag posts and comments with an optional reason and detail, unflag them, and check flag status."
---

Use content flagging APIs when users need to report posts or comments for review. A report can say _why_ with a reason, and add the reporter's own words as an optional detail, so moderators see the context without a follow-up. The SDK supports flagging, unflagging, and checking whether the current user has flagged a loaded item.

<Info>
  TypeScript, iOS, and Android flag posts and comments with no reason, or with a
  reason and an optional detail. Flutter flags posts and comments without a
  reason; its public post and comment flag builders do not accept a reason yet.
</Info>

## Flag reasons

A reason is one fixed category. On Android, iOS, and TypeScript it never carries text: the reporter's own words always go in `detail`. Flutter uses these reasons for messages only, and its Others reason carries the text.

| Reason | Android `AmityContentFlagReasonType` | iOS `AmityContentFlagReasonType` | TypeScript `ContentFlagReasonEnum` | Flutter `AmityContentFlagReason` (messages only) |
| --- | --- | --- | --- | --- |
| Against community guidelines | `COMMUNITY_GUIDELINES` | `.communityGuidelines` | `CommunityGuidelines` | `communityGuidelines` |
| Harassment or bullying | `HARASSMENT_OR_BULLYING` | `.harassmentOrBullying` | `HarassmentOrBullying` | `harassmentOrBullying` |
| Self-harm or suicide | `SELF_HARM_OR_SUICIDE` | `.selfHarmOrSuicide` | `SelfHarmOrSuicide` | `selfHarmOrSuicide` |
| Violence or threatening content | `VIOLENCE_OR_THREATENING_CONTENT` | `.violenceOrThreateningContent` | `ViolenceOrThreateningContent` | `violenceOrThreateningContent` |
| Selling and promoting restricted items | `SELLING_RESTRICTED_ITEMS` | `.sellingRestrictedItems` | `SellingRestrictedItems` | `sellingRestrictedItems` |
| Sexual content or nudity | `SEXUAL_CONTENT_OR_NUDITY` | `.sexualContentOrNudity` | `SexualContentOrNudity` | `sexualContentOrNudity` |
| Spam or scams | `SPAM_OR_SCAMS` | `.spamOrScams` | `SpamOrScams` | `spamOrScams` |
| False information or misinformation | `FALSE_INFORMATION` | `.falseInformation` | `FalseInformation` | `falseInformation` |
| Others | `OTHERS` | `.others` | `Others` | `others('...')` |

## Parameters

| Operation | Parameter | Required | Platforms | Description |
| --- | --- | --- | --- | --- |
| Flag a post or comment | `postId` / `commentId` | Yes | All | ID of the content to report. |
| Flag a post or comment | `reason` | No | Android, iOS, TypeScript | One reason from the table above. Omit it to flag without a reason. |
| Flag a post or comment | `detail` | No | Android, iOS, TypeScript | The reporter's own words, for any reason including Others. Needs a `reason`. Sent as given; omitted when not set. The server limits it to 300 characters. |
| Unflag content | `postId` / `commentId` | Yes | All | Content ID whose current-user report should be removed. |
| Check flag status | `postId` / `commentId` or loaded model | Yes | All | Checks whether the current user has flagged the item. |

<Note>
  A `detail` without a `reason` is not possible: every call that takes `detail`
  also requires `reason`. On TypeScript, a malformed options object is rejected
  before any request is sent.
</Note>

## Flag a post

Flag a post when a member reports it. Pass a reason when your report menu offers one, and pass the reporter's text as `detail` when they add some. Use the no-reason call when your UI only offers a single "Report" action.

<CodeGroup>

```kotlin Android
val postRepository = AmitySocialClient.newPostRepository()

// Reason with the reporter's own words
postRepository
    .flagPost(
        postId = postId,
        reason = AmityContentFlagReasonType.SPAM_OR_SCAMS,
        detail = "Repeated promotional links",
    )
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )

// Reason only
postRepository
    .flagPost(postId, AmityContentFlagReasonType.HARASSMENT_OR_BULLYING)
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )

// No reason
postRepository
    .flagPost(postId = postId)
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )
```

```swift iOS
let repository = AmityPostRepository()

// Reason with the reporter's own words
try await repository.flagPost(
    withId: "post-id",
    reason: .spamOrScams,
    detail: "Repeated promotional links"
)

// Reason only: type the reason explicitly so the current call is used
try await repository.flagPost(
    withId: "post-id",
    reason: AmityContentFlagReasonType.harassmentOrBullying
)

// No reason
try await repository.flagPost(withId: "post-id")
```

```typescript TypeScript
import { ContentFlagReasonEnum, PostRepository } from '@amityco/ts-sdk';

// Reason with the reporter's own words
const didFlag = await PostRepository.flagPost(postId, {
  reason: ContentFlagReasonEnum.SpamOrScams,
  detail: 'Repeated promotional links',
});

if (didFlag) {
  showSuccessMessage('Post flagged');
}

// Reason only
await PostRepository.flagPost(postId, { reason: ContentFlagReasonEnum.HarassmentOrBullying });

// No reason
await PostRepository.flagPost(postId);
```

```dart Flutter
// Flutter flags posts without a reason
final didFlag = await post.report().flag();

if (didFlag) {
  // Show flagged state.
}
```

</CodeGroup>

## Flag a comment

Flag a comment the same way: no reason, or a reason with an optional `detail`.

<CodeGroup>

```kotlin Android
val commentRepository = AmitySocialClient.newCommentRepository()

// Reason with the reporter's own words
commentRepository
    .flagComment(
        commentId = commentId,
        reason = AmityContentFlagReasonType.HARASSMENT_OR_BULLYING,
        detail = "Insults another member in every reply",
    )
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )

// No reason
commentRepository
    .flagComment(commentId = commentId)
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )
```

```swift iOS
let repository = AmityCommentRepository()

// Reason with the reporter's own words
try await repository.flagComment(
    withId: "comment-id",
    reason: .harassmentOrBullying,
    detail: "Insults another member in every reply"
)

// No reason; returns a Bool
let didFlag = try await repository.flagComment(withId: "comment-id")
```

```typescript TypeScript
import { CommentRepository, ContentFlagReasonEnum } from '@amityco/ts-sdk';

// Reason with the reporter's own words
const didFlag = await CommentRepository.flagComment(commentId, {
  reason: ContentFlagReasonEnum.HarassmentOrBullying,
  detail: 'Insults another member in every reply',
});

if (didFlag) {
  showSuccessMessage('Comment flagged');
}

// No reason
await CommentRepository.flagComment(commentId);
```

```dart Flutter
// Flutter flags comments without a reason
final didFlag = await comment.report().flag();

if (didFlag) {
  // Show flagged state.
}
```

</CodeGroup>

## Report with Others

Use the Others reason when none of the categories fit. Put the reporter's explanation in `detail`, exactly as for any other reason.

<CodeGroup>

```kotlin Android
AmitySocialClient.newPostRepository()
    .flagPost(
        postId = postId,
        reason = AmityContentFlagReasonType.OTHERS,
        detail = "Shares a member's home address",
    )
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )
```

```swift iOS
try await AmityPostRepository().flagPost(
    withId: "post-id",
    reason: .others,
    detail: "Shares a member's home address"
)
```

```typescript TypeScript
import { ContentFlagReasonEnum, PostRepository } from '@amityco/ts-sdk';

await PostRepository.flagPost(postId, {
  reason: ContentFlagReasonEnum.Others,
  detail: "Shares a member's home address",
});
```

</CodeGroup>

<Note>
  The earlier calls that took only a reason are **deprecated** but still work:
  `flagPost(postId, reason)` and `flagComment(commentId, reason)` with a reason
  string on TypeScript, and with `AmityContentFlagReason` on Android and iOS,
  where custom text was passed as `Others("...")` / `.others("...")`. Move custom
  text to `detail` with the Others reason. Flagging with only an ID is not
  deprecated.
</Note>

## Unflag content

Unflag content when the current user removes their own report from a post or comment.

<CodeGroup>

```kotlin Android
AmitySocialClient.newPostRepository()
    .unflagPost(postId = postId)
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )

AmitySocialClient.newCommentRepository()
    .unflagComment(commentId = commentId)
    .subscribe(
        { showSuccessMessage() },
        { error -> handleGeneralError(error) },
    )
```

```swift iOS
let postRepository = AmityPostRepository()
let commentRepository = AmityCommentRepository()

try await postRepository.unflagPost(withId: "post-id")
try await commentRepository.unflagComment(withId: "comment-id")
```

```typescript TypeScript
import { CommentRepository, PostRepository } from '@amityco/ts-sdk';

const didUnflagPost = await PostRepository.unflagPost(postId);
const didUnflagComment = await CommentRepository.unflagComment(commentId);
```

```dart Flutter
final didUnflagPost = await post.report().unflag();
final didUnflagComment = await comment.report().unflag();
```

</CodeGroup>

## Check flag status

Check flag status before rendering a flag or unflag action for the loaded item.

<CodeGroup>

```kotlin Android
val loadedPost = post ?: return
val loadedComment = comment ?: return

val isPostFlagged = loadedPost.isFlaggedByMe()
val isCommentFlagged = loadedComment.isFlaggedByMe()
```

```swift iOS
let postRepository = AmityPostRepository()
let commentRepository = AmityCommentRepository()

let isPostFlagged = try await postRepository.isFlaggedByMe(withId: "post-id")
let isCommentFlagged = try await commentRepository.isCommentFlaggedByMe(withId: "comment-id")
```

```typescript TypeScript
import { CommentRepository, PostRepository } from '@amityco/ts-sdk';

const isPostFlagged = await PostRepository.isPostFlaggedByMe(postId);
const isCommentFlagged = await CommentRepository.isCommentFlaggedByMe(commentId);
```

```dart Flutter
final isPostFlagged = post.isFlaggedByMe;
final isCommentFlagged = comment.isFlaggedByMe;
```

</CodeGroup>

<Warning>
Flagging creates report state; it does not delete, hide, approve, or decline content by itself. For review workflows, use the moderation tools available in Console and the SDK APIs for the content type you are moderating.
</Warning>

## Platform notes

- Reason with optional detail ships in TypeScript 7.29.0 and in the October 2026 iOS and Android releases.
- On iOS, when you omit `detail`, write the reason with its type, for example `AmityContentFlagReasonType.spamOrScams`. The shorthand `.spamOrScams` on its own selects the deprecated call.
- A flag without a reason is recorded with a default reason: Others on TypeScript and Android, and Against community guidelines on iOS.
- Flutter flags posts and comments without a reason.
