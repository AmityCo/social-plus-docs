Use `AmityFeedRepository` to read feed-style post collections. Each feed is a separate SDK entry point over the same content — what changes is who the posts are selected for, and how they are ordered.

<CardGroup cols={2}>
  <Card title="For You Feed" icon="sparkles" href="/social-plus-sdk/social/discovery-engagement/feed/for-you-feed">
    **Personalized per user.** The backend picks posts from the user's communities, follows, public content, and live streams, then ranks them. Requires the network setting.
  </Card>
  <Card title="Global Feed" icon="clock" href="/social-plus-sdk/social/discovery-engagement/feed/global-feed">
    **Chronological.** The most recent posts come first. Use it for a real-time content stream.
  </Card>
  <Card title="Custom-Ranking Global Feed" icon="star" href="/social-plus-sdk/social/discovery-engagement/feed/custom-ranking">
    **Score-sorted.** The same global content, ordered by engagement, recency, and updates rather than by time alone.
  </Card>
  <Card title="User & Community Feeds" icon="users" href="/social-plus-sdk/social/content-management/posts/retrieval/query-posts">
    **Scoped to one owner.** Query posts for a single user or community, with richer filters.
  </Card>
</CardGroup>

## Choosing a feed

| If you need | Use | Ordering |
| --- | --- | --- |
| A discovery tab tailored to each user | [For You feed](/social-plus-sdk/social/discovery-engagement/feed/for-you-feed) | Backend-personalized and ranked |
| A live stream of everything happening now | [Global feed](/social-plus-sdk/social/discovery-engagement/feed/global-feed) | Newest first |
| A global feed that surfaces what people engage with | [Custom-ranking global feed](/social-plus-sdk/social/discovery-engagement/feed/custom-ranking) | Engagement score |
| One user's or one community's posts | [Query posts](/social-plus-sdk/social/content-management/posts/retrieval/query-posts) | Newest first, with filters |

<Info>
For You feed is a network-level feature and must be enabled for your network before it returns content. The global and custom-ranking feeds are available to every network.
</Info>

## Feed APIs

| Feed | TypeScript | iOS | Android | Flutter |
| --- | --- | --- | --- | --- |
| For You feed | `FeedRepository.getForYouFeed()` | Supported | Supported | Not available |
| Global feed | `FeedRepository.getGlobalFeed()` | `AmityFeedRepository().getGlobalFeed()` | `AmitySocialClient.newFeedRepository().getGlobalFeed()` | `AmitySocialClient.newFeedRepository().getGlobalFeed()` |
| Custom-ranking global feed | `FeedRepository.getCustomRankingGlobalFeed()` | `AmityFeedRepository().getCustomRankingGlobalFeed()` | `AmitySocialClient.newFeedRepository().getCustomRankingGlobalFeed()` | `AmitySocialClient.newFeedRepository().getCustomRankingGlobalFeed()` |
| User feed | `FeedRepository.getUserFeed()` | `AmityFeedRepository().getUserFeed()` | `AmitySocialClient.newFeedRepository().getUserFeed()` | `AmitySocialClient.newFeedRepository().getUserFeed()` |
| Community feed | `FeedRepository.getCommunityFeed()` | `AmityFeedRepository().getCommunityFeed()` | `AmitySocialClient.newFeedRepository().getCommunityFeed()` | `AmitySocialClient.newFeedRepository().getCommunityFeed()` |

<Note>
TypeScript still exports `queryGlobalFeed()`, but the SDK source marks it deprecated. Use the live collection APIs for new integrations.
</Note>

## Notes

- Use post query APIs when you need a specific user or community feed with richer filters such as tags, review status, or deletion state.
- Dispose live collection subscriptions, notification tokens, and stream subscriptions when the screen is destroyed.
- Ranking is backend-owned on every feed that has it. Do not hardcode ranking assumptions in client UI logic.
