title: "Global Feed"
description: "Query the network-wide feed chronologically, or use the custom-ranking global feed that orders posts by engagement."
---

The global feed returns posts from across the network. There are two entry points, and they differ only in how the backend orders the results.

<CardGroup cols={2}>
  <Card title="Global feed" icon="clock">
    Chronological. The most recent posts come first. Use it for a real-time content stream.
  </Card>
  <Card title="Custom-ranking global feed" icon="star">
    Score-sorted. Posts are ordered by engagement, recency, and updates rather than by time alone.
  </Card>
</CardGroup>

<Info>
The global feed shows at most the 20 most recent posts per community. Older posts from the same community are not included.
</Info>

## Parameters

| Parameter | Applies to | Required | Description |
| --- | --- | --- | --- |
| `dataTypes` | Global feed | No | Filter the feed to specific post content types, such as image or video. |
| `includeMixedStructure` | Both | No | Include mixed-structure posts alongside the requested data type filters. |
| `limit` | TypeScript | No | Page size for the live collection. Defaults to 20. |
| `invalidateCache` | Android | No | Skip cached paging data for deliberate refresh flows. |

## Query global feed

Use data type filters when your UI only needs a subset of post types, such as an image or video feed.

<CodeGroup>

```typescript TypeScript
import { FeedRepository } from '@amityco/ts-sdk';

let loadNextPage: (() => void) | undefined;
let canLoadMore = false;

const unsubscribe = FeedRepository.getGlobalFeed(
  {
    dataTypes: ['image', 'video'],
    includeMixedStructure: true,
    limit: 20,
  },
  ({ data: posts, onNextPage, hasNextPage, loading, error }) => {
    if (loading) return;
    if (error) {
      handleError(error);
      return;
    }

    renderResults(posts);
    loadNextPage = onNextPage;
    canLoadMore = hasNextPage;
  },
);

function loadMoreGlobalFeed() {
  if (canLoadMore) {
    loadNextPage?.();
  }
}

unsubscribe();
```

```swift iOS
token = feedRepository
    .getGlobalFeed(dataTypes: Set(["image", "video"]), includeMixedStructure: true)
    .observe { collection, error in
        if let error {
            handleError(error)
            return
        }

        showSuccessMessage(collection.snapshots.count)
    }
```

```kotlin Android
AmitySocialClient.newFeedRepository()
    .getGlobalFeed()
    .dataTypes(listOf(AmityPost.DataType.IMAGE, AmityPost.DataType.VIDEO))
    .includeMixedStructure(includeMixedStructure = true)
    .build()
    .query()
    .subscribe(
        { pagingData: PagingData<AmityPost> -> showSuccessMessage(pagingData) },
        { error -> handleGeneralError(error) }
    )
```

```dart Flutter
final page = await AmitySocialClient.newFeedRepository()
    .getGlobalFeed()
    .types([AmityDataType.IMAGE, AmityDataType.VIDEO])
    .getPagingData(limit: 20);

final posts = page.data;
showError(posts.length);
```

</CodeGroup>

## Custom-ranking global feed

Use the custom-ranking global feed when your app has enabled the backend-ranked global feed experience. The SDK does not expose ranking weights or formulas; it only requests the custom-ranking feed and returns the posts the backend provides.

## How custom ranking orders posts

Chronological ordering treats every post the same, regardless of whether anyone engaged with it. Custom ranking instead sorts on a score built from "meaningful interactions":

| Factor | Effect on the score |
| --- | --- |
| Comments | Raises the score, weighted more heavily than reactions — a comment is deeper engagement than a reaction |
| Reactions | Raises the score |
| Age (`createdAt`) | Decays the score over time, so the feed stays fresh |
| Updates and edits (`updatedAt`, `editedAt`) | Temporarily boosts the score, keeping revised content visible |

Scores are recalculated on every query, so pagination results can shift while users interact with the content.

<Warning>
- New posts appear in the user feed immediately, but may take a moment to appear in the custom-ranking global feed while the score is calculated.
- The exact weights and decay curve are backend-owned and are not exposed through the SDK. To tune them for your network, contact [social.plus Support](https://ekoapp.atlassian.net/servicedesk/customer/portal/3) with your ranking requirements.
</Warning>
