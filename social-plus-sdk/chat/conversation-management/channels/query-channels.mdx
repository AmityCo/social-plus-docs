---
title: "Query Channels"
description: "Query chat channels by type, membership, tags, deletion state, archive state, sort order, or known channel IDs."
---

Use channel queries to build inboxes, public channel discovery, event chat lists, and moderation views. Query support is similar across platforms, but not identical: TypeScript and Flutter expose keyword/display-name style searching, while Android's public channel query builder focuses on type, membership, tags, and deleted-state filters.

## Filter Surface

| Filter | TypeScript | iOS | Android | Flutter |
| --- | --- | --- | --- | --- |
| Types | `types` | `types` | `.types(...)` or type helpers | `.types(...)` or type helpers |
| Membership | `membership` | `filter` | `.filter(...)` where the builder exposes it | `.filter(...)` |
| Tags | `tags`, `excludeTags` | `includingTags`, `excludingTags` | `.includingTags(...)`, `.excludingTags(...)` | `.includingTags(...)`, `.excludingTags(...)` |
| Deleted state | `isDeleted` | `includeDeleted` | `.includeDeleted(...)` | `.includeDeleted(...)` |
| Name or keyword | `displayName` | Not exposed on `AmityChannelQueryOptions` | Not exposed on public query builder | `.withKeyword(...)` |
| Archive exclusion | `excludeArchives` | `excludeArchives` on `AmityChannelQueryOptions` | `.excludeArchived(...)` | `.excludeArchives(...)` |
| Sort | `sortBy` | `sortBy` with `.lastActivity` or `.lastMessage` | Not exposed on public query builder | `.sortBy(...)` with `LAST_ACTIVITY` |
| Known IDs | `channelIds` | `getChannels(channelIds:)` | `getChannels(channelIds)` | Not exposed in the current public repository |

## Parameters

| Parameter | Required | Platforms | Description |
| --- | --- | --- | --- |
| `types` | No | TypeScript, iOS, Android, Flutter | Channel types to include, such as community, live, or conversation. |
| `membership` / `filter` | No | TypeScript, iOS, Android, Flutter | Restrict results by the current user's relationship to the channel. |
| `tags` / `includingTags` | No | TypeScript, iOS, Android, Flutter | Include channels with specific app-defined tags. |
| `excludeTags` / `excludingTags` | No | TypeScript, iOS, Android, Flutter | Exclude channels with specific app-defined tags. |
| `isDeleted` / `includeDeleted` | No | TypeScript, iOS, Android, Flutter | Include or exclude deleted channels where the platform exposes the filter. |
| `displayName` / `keyword` | No | TypeScript, Flutter | Search by name or keyword where supported by the platform SDK. |
| `excludeArchives` | No | TypeScript, iOS, Android, Flutter | Exclude channels archived by the current user where supported. |
| `sortBy` | No | TypeScript, iOS, Flutter | Sort channel lists where the platform exposes sort options. On iOS, choose `.lastActivity` (default) or `.lastMessage`; see [Sort A Channel List](#sort-a-channel-list). |
| Pagination controls | No | TypeScript, iOS, Android, Flutter | Use collection callbacks, live collections, or paging data to load additional channels. |

## Query A Channel List

Query channels with type, membership, tag, deletion, archive, search, and pagination options where each platform exposes them.

<CodeGroup>

```kotlin Android
val includingTags = AmityTags().apply { add("support") }
val excludingTags = AmityTags().apply { add("hidden") }

val disposable = channelRepository
    .getChannels()
    .types(listOf(AmityChannel.Type.COMMUNITY, AmityChannel.Type.LIVE))
    .filter(AmityChannelFilter.MEMBER)
    .includingTags(includingTags)
    .excludingTags(excludingTags)
    .includeDeleted(includeDeleted = false)
    .build()
    .query()
    .subscribe(
        { pagingData -> showSuccessMessage(pagingData) },
        { error -> handleGeneralError(error) },
    )
```

```swift iOS
let options = AmityChannelQueryOptions(
    types: Set([AmityChannelQueryType.community, AmityChannelQueryType.live]),
    filter: .userIsMember,
    includingTags: ["support"],
    excludingTags: ["hidden"],
    includeDeleted: false,
    sortBy: .lastMessage
)

let channels = channelRepository.getChannels(with: options)
token = channels.observe { collection, error in
    if let error {
        handleError(error)
        return
    }

    showSuccessMessage(collection.snapshots.count)
}
```

```typescript TypeScript
import { ChannelRepository } from '@amityco/ts-sdk';

const unsubscribe = ChannelRepository.getChannels(
  {
    displayName: 'support',
    membership: 'member',
    types: ['community', 'live'],
    tags: ['support'],
    excludeTags: ['hidden'],
    isDeleted: false,
    excludeArchives: true,
    sortBy: 'lastActivity',
  },
  ({ data: channels, onNextPage, hasNextPage, loading, error }) => {
    if (error) handleError(error);

    if (!loading && channels) {
      renderResults(channels);
    }

    if (hasNextPage) onNextPage?.();
  },
);

unsubscribe();
```

```dart Flutter
final liveCollection = AmityChatClient.newChannelRepository()
    .getChannels()
    .withKeyword('support')
    .filter(AmityChannelFilter.MEMBER)
    .types([AmityChannelType.COMMUNITY, AmityChannelType.LIVE])
    .includingTags(['support'])
    .excludingTags(['hidden'])
    .includeDeleted(false)
    .excludeArchives(true)
    .sortBy(AmityChannelSortOption.LAST_ACTIVITY)
    .getLiveCollection();

liveCollection.getStreamController().stream.listen((channels) {
  final count = channels.length;
});

await liveCollection.loadNext();
```

</CodeGroup>

## Sort A Channel List

Use `sortBy` to choose how a channel list is ordered. Choose `.lastMessage` for an inbox that should follow the conversation, so that joining or leaving a channel does not push it to the top. On iOS, `AmityChannelQueryOptions.sortBy` takes an `AmityChannelSortBy`:

| Value | Order | What moves a channel to the top |
| --- | --- | --- |
| `.lastActivity` (default) | Newest activity first | A new message, or a member being added, removed, or banned |
| `.lastMessage` | Newest message first | A new message. Membership changes do not reorder the list. |

<CodeGroup>

```swift iOS
// Newest message first
let options = AmityChannelQueryOptions(
    filter: .userIsMember,
    sortBy: .lastMessage
)

let channels = channelRepository.getChannels(with: options)
token = channels.observe { collection, error in
    if let error {
        handleError(error)
        return
    }

    for channel in collection.snapshots {
        showRow(name: channel.displayName, lastMessageAt: channel.lastMessageAt)
    }
}
```

</CodeGroup>

- **Live order.** The collection reorders as messages arrive. When the current user sends a message, that channel moves to the top right away, before the server responds.
- **`lastMessageAt`.** `AmityChannel.lastMessageAt` is the time of the channel's newest message, or its creation time if it has none. Unlike `lastActivity`, membership changes and closing the channel do not change it. It is `nil` when the backend has no value for the channel yet, and those channels are listed last, ordered by creation time.
- **Backend support.** `.lastMessage` needs backend support for your network. Until it is available, the query fails with `AmityErrorCode.business` (HTTP 422). The SDK does not retry and does not fall back to `.lastActivity`, so handle the error in the collection's `observe` block. `error.isAmityErrorCode(.business)` identifies it.

<Info>
This page documents `.lastMessage` for iOS. The other platforms' sort options are listed in the tables above; check each platform's release notes for availability.
</Info>

## Query A Specific Type

Use the type-specific helpers when the platform exposes them. Some helpers apply membership defaults: for example, Flutter's `conversationType()` and `liveType()` also set the filter to `MEMBER`.

Use type-specific channel queries when your UI needs a focused list such as conversations or live channels.

<CodeGroup>

```kotlin Android
val disposable = channelRepository
    .getChannels()
    .conversationType()
    .includeDeleted(includeDeleted = false)
    .build()
    .query()
    .subscribe(
        { pagingData -> showSuccessMessage(pagingData) },
        { error -> handleGeneralError(error) },
    )
```

```swift iOS
let options = AmityChannelQueryOptions(
    types: Set([AmityChannelQueryType.conversation]),
    filter: .userIsMember,
    includeDeleted: false
)

let conversations = channelRepository.getChannels(with: options)
showSuccessMessage(conversations)
```

```typescript TypeScript
import { ChannelRepository } from '@amityco/ts-sdk';

const unsubscribe = ChannelRepository.getChannels(
  {
    types: ['conversation'],
    membership: 'member',
    isDeleted: false,
  },
  ({ data: channels }) => {
    renderResults(channels);
  },
);

unsubscribe();
```

```dart Flutter
final conversations = AmityChatClient.newChannelRepository()
    .getChannels()
    .conversationType()
    .includeDeleted(false)
    .excludeArchives(true)
    .getLiveCollection();

conversations.getStreamController().stream.listen((channels) {
  final count = channels.length;
});
```

</CodeGroup>

## Known IDs

If you already have channel IDs, use [Get Channels](./get-channel) instead of a filtered query. Batch get-by-IDs is currently exposed on TypeScript, iOS, and Android.
