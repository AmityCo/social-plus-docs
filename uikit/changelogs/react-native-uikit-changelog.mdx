<Update label="4.3.1  (25/09/2026)" tags={["New Releases"]}>
  ## 🚀 New Features

  #### Standalone Chat Pages

  All 16 chat pages are now exported from the package root under the same names as the Web UIKit, so you can render any one of them inside `AmityPageRenderer`. For example, render `<AmityChatPage channelId="..." />` to open a conversation straight from a push notification. Each page that takes input exports a `<PageName>Props` type, such as `AmityChatPageProps`. From a rendered page, users can still move on to the other chat pages. See [Render a Single Chat Page](/uikit/getting-started/installation#render-a-single-chat-page).

<Update label="4.3.0  (25/09/2026)" tags={["New Releases","Improvements"]}>
  ## 🚀 New Features

  #### Chat UIKit

  The React Native UIKit now includes in-app messaging. Render the new `AmityUiKitChat` entry point inside `AmityUiKitProvider` to mount the chat experience. It needs no extra package. See [Add Chat](/uikit/getting-started/installation#add-chat).

  - **Chat list**: browse, search, and archive conversations, with unread and mention badges.
  - **One-to-one and group chats**: send text, images, and videos, reply to messages, mention members, and see link previews.
  - **Message actions**: react, copy, edit, delete (with confirmation), report, and save photos or videos to the gallery. Failed messages can be resent from the message bubble.
  - **Search**: find chats and messages from the chat list, and jump straight to a matching message.
  - **Group management**: create groups, edit the group name and avatar, add and remove members, and manage banned users.
  - **Moderation**: moderators can delete any message. Users can report, unreport, and block other users. Chats with blocked users are hidden from search.
  - **Notifications**: chat notification settings, plus a banner when push notifications have been disabled by an admin.
  - Brand and moderator badges are shown throughout chat.

  #### Chat Navigation Behaviors

  Handle avatar and @mention taps in your own app through `AmityChatPageBehavior` and `AmityMessageBubbleBehavior`. See [Customize Navigation](/uikit/components/chat/conversation-chat#customize-navigation-react-native).

  ## ✨ Improvements

  - Bottom sheets across the UIKit now open, resize, and drag more smoothly.
  - Chat ships with English and Thai string bundles. The package doesn't yet expose an API to switch language — see [Localization](/uikit/customization/localization).
  - Upgraded the social.plus SDK dependency (`@amityco/ts-sdk-react-native`) to `^7.28.0`.

  ## 🚨 Compatibility Changes

  - **iOS:** add `NSPhotoLibraryAddUsageDescription` to your app's `Info.plist` before upgrading. Saving a photo or video from chat asks iOS for permission to add to the photo library, and iOS terminates an app that asks without this key.
  - **Android:** declare `WRITE_EXTERNAL_STORAGE` with `android:maxSdkVersion="28"` in your app's `AndroidManifest.xml`. Android 9 and below need it to save to the gallery; without it, saving always fails with a permission error.
  - **New peer dependencies:** `react-native-reanimated` `~4.3.4`, `react-native-worklets` `~0.8.3`, and `@react-native-camera-roll/camera-roll` `^7.10.2`. Add `'react-native-worklets/plugin'` as the **last** plugin in your app's `babel.config.js`.
  - `@react-native-community/netinfo` must now be `>=11.5.0`. `react-native-netinfo` is no longer required.

  See [Installation](/uikit/getting-started/installation) for the full setup.
