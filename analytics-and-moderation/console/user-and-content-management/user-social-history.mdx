## Accessing User History

<Steps>
  <Step title="Open Manage Users">
    Navigate: Users → Manage Users. You can also filter users by [tags](/analytics-and-moderation/console/user-and-content-management/tag-management) to quickly narrow down specific segments before opening their history.
  </Step>

  <Step title="Select User">
    Click any user row to open Social History panel.
  </Step>

  <Step title="Alternate Paths">
    Click username from Posts & Comments or Community Member list.
  </Step>

  <Step title="Review Snapshot">
    Begin with headline metrics before deep dive.
  </Step>
</Steps>

## Snapshot Metrics

The profile card at the top of the page has three parts.

**Profile**

- Name, profile creation date, following and follower counts, description, and global role
- The **⋮** menu: assign tags, change global role, profile moderation, [global mute/unmute](/analytics-and-moderation/console/user-and-content-management/global-mute), global ban/unban, and copy user ID

**Moderation**

The left side shows what is active on the user right now. Each row appears only when it has something to show.

| Row | Shows |
| --- | --- |
| **Status** | **Globally banned** and **Muted** badges. Hover over **Muted** to see when the mute expires. |
| **User** | Flags on the user's profile: AI moderation detections (labeled with the detected category), reports from users (grouped by report type, for example "Username (2), Behavior (1)"), and flags from admins (labeled with the reason). |
| **Content** | The number of flagged posts and flagged comments. Click either count to open the Posted or Commented & replied tab filtered to flagged items. |

The right side shows the user's moderation record: the total number of moderation actions, and one badge per action type that has happened, with its count. The action types are community bans, community removals, global bans, global mutes, and profile resets.

A user with no active flags and no moderation actions shows a single line: **Nothing active**, "No flags on the user, posts or comments", and "No moderation actions on record".

Counts update as you act. For example, clearing a flag lowers the flagged count, and banning or muting the user from the **⋮** menu updates the moderation record.

**Activity**

- Totals for posts, comments, reactions, and communities joined
- The user's [Contribution level](/analytics-and-moderation/console/user-and-content-management/user-insights)

Counts of 1,000 or more are shortened, for example 1.2K or 45M. Hover over a shortened count to see the exact number.

  </Tab>
</Tabs>

## Interpretation Framework

<AccordionGroup>
  <Accordion title="Engagement Density">
    High comments vs low posts may indicate conversational contributor; high reactions with low authored content may signal passive engager or reaction spam.
  </Accordion>

  <Accordion title="Flag Pattern Analysis">
    Clustered flags in narrow time windows suggest episodic behavior; distributed flags indicate chronic issues.
  </Accordion>

  <Accordion title="Cross-Community Influence">
    Multiple high-activity communities = broader impact; concentrated activity aids targeted intervention.
  </Accordion>

  <Accordion title="Moderation Escalation">
    Depending on your moderation policy and the case, you can remove individual content, apply a timed global mute to stop contributions across the network while preserving read access, restrict participation in a community, or globally ban the user to block network access.
  </Accordion>
</AccordionGroup>

## Decision Playbooks

<Tabs>
  <Tab title="Low-Risk Noise">
    Minor isolated flags; advise user via response, monitor trend.
  </Tab>

  <Tab title="Repeat Local Violations">
    Pattern in 1 community → community ban period, educate, reassess.
  </Tab>

  <Tab title="Cross-Community Abuse">
    For reports across several communities, review the user's moderation history and consider a global mute to stop further contributions while the case is assessed. Apply a global ban when your moderation policy calls for blocking network access.
  </Tab>

  <Tab title="Escalation Case">
    Severe violation (threats, explicit abuse) → immediate global ban \+ document for compliance.
  </Tab>

  <Tab title="Rehabilitation">
    Declining violation trend post-warning → reduce restrictions; track next 30 days.
  </Tab>
</Tabs>

## Metrics to Monitor

| Metric                  | Insight                  | Action Trigger                        |
| ----------------------- | ------------------------ | ------------------------------------- |
| Flags / 30 days         | Current behavioral risk  | Sudden spike vs baseline              |
| Flag clearance rate     | Moderator responsiveness | Low clearance → adjust staffing       |
| Communities engaged     | Breadth of influence     | High \+ rising flags → broader review |
| Reaction-to-post ratio  | Engagement style         | Extreme imbalance → review for spam   |
| Ban recurrence interval | Escalation need          | Short intervals → stronger sanction   |

## Best Practices

<AccordionGroup>
  <Accordion title="Effective Assessment">
    - Start with snapshot metrics before deep scroll.
    - Correlate flags with content type & community.
    - Validate if spikes align with platform events (launches, campaigns).
  </Accordion>
  <Accordion title="Consistent Moderation">
    - Reference prior actions to avoid double-penalizing.
    - Apply same thresholds across communities.
    - Document rationale for escalations externally when required.
  </Accordion>
  <Accordion title="Community Impact">
    - Identify positive contributors for recognition programs.
    - Track disengagement after sanctions (potential churn risk).
    - Use distribution of contributions to guide community staffing.
  </Accordion>
</AccordionGroup>

## Troubleshooting

| Issue                               | Likely Cause                        | Resolution                                    |
| ----------------------------------- | ----------------------------------- | --------------------------------------------- |
| Missing reactions pre Nov 28 2024   | Historical limit                    | Data collection started then; no retro import |
| Removed not showing pre Dec 19 2024 | Feature availability start          | Only tracked from release date                |
| Flags count mismatch                | Recently cleared / delayed sync     | Refresh or wait sync cycle                    |
| Cannot change global role           | Permission scope lacking            | Adjust admin role privileges                  |
| Ban option disabled                 | Already globally banned             | Unban first to reapply variant action         |
| Mute option unavailable             | Brand account, or insufficient role | Brand accounts cannot be globally muted       |
| Community missing from list         | Deleted & purged / permission scope | Confirm retention policy / scope              |
